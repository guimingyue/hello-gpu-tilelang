# 第 5 课 控制流与编译时参数

> 本课的问题：每个元素先做 ReLU（负数变 0），再重复 `x ← 0.5x + 1` 若干次。不同元素之间互不依赖，但**同一个元素的每一步依赖上一步**。这正好逼出两个概念：哪些循环可以并行，哪些必须串行；哪些值是运行时数据，哪些是编译时参数。

## 5.1 先手算

输入 `[-4, -2, 0, 2, 4]`，ReLU 后 `[0, 0, 0, 2, 4]`：

| steps | 输出 |
| --- | --- |
| 0 | `[0, 0, 0, 2, 4]` |
| 1 | `[1, 1, 1, 2, 3]` |
| 2 | `[1.5, 1.5, 1.5, 2, 2.5]` |
| 8 | `[1.9921875, 1.9921875, 1.9921875, 2, 2.0078125]` |

递推 `x ← 0.5x + 1` 的不动点是 2：无论初值多少，步数够多都趋近 2。steps=8 时 0 走到 `2 - 2/256 = 1.9921875`，4 走到 `2 + 2/256 = 2.0078125`——这些值都能被 FP32 精确表示，所以可以零容差校验。

## 5.3 三种“循环/分支”，三种含义

```python
with T.Kernel(T.ceildiv(n, block), threads=32) as bx:
    for i in T.Parallel(block):        # ① 可并行：不同元素
        idx = bx * block + i
        if idx < n:
            if A[idx] > 0:             # ② 数据相关分支：每个元素自己的判断
                B[idx] = A[idx]
            else:
                B[idx] = 0
            for step in T.serial(steps):   # ③ 必须串行：同一元素的递推
                B[idx] = 0.5 * B[idx] + 1
```

- **① `T.Parallel`**：声明迭代间无依赖，编译器可映射到不同线程。第 4 课已见。
- **② `if A[idx] > 0`**：分支条件来自**数据**。GPU 上同一组线程可能走不同分支（发散），硬件会处理，但发散有代价——本课只要求写对，性能讨论留给实战篇。
- **③ `T.serial`**：声明迭代间**有依赖**，必须按顺序。把递推写成 `T.Parallel` 是语义错误：第 2 步会读到还没算出的第 1 步结果。

还有一层不在 kernel 里：`make_transform(n, steps)` 是**普通 Python 函数**，`for _ in range(steps)` 出现在参考实现里是主机循环。主机循环每次迭代都真实执行；kernel 里的 `T.serial(steps)` 是被编译进设备代码的循环。

## 5.4 编译时参数：steps 为什么能当循环次数

`steps` 是 Python 整数，在**编译时**已知。编译器据此生成确定次数的循环（甚至展开）。这意味着：

- 改 `steps` 会触发**重新编译**（新的特化版本），不是运行时改个变量；
- 形状 `n`、块大小 `block` 同理——这就是第 3 课 `make_add(n, block)` 工厂模式的意义：**为每组编译时参数造一个 kernel**；
- 运行时才知道的值（比如张量里的数）不能这样用，它们只能走数据分支。

这也是 TileLang 与“解释执行”的根本区别之一：很多灵活性在编译期兑现，换来设备代码的确定性。

## 5.5 改一个条件

把 `--steps` 从 2 改成 8，观察输出趋近 2；再改成 0，确认递推完全不执行、输出就是 ReLU 结果。每次改变都重新编译——注意日志里 `begins to compile` 的出现时机。

## 5.6 练习与自检

1. 为什么递推循环不能用 `T.Parallel`？用一句话说明依赖关系。
2. `if idx < n` 和 `if A[idx] > 0` 都是 if，本质区别是什么？
3. 想让 steps 在运行时由用户输入决定、不重新编译，本课的写法能做到吗？

<details>
<summary>参考答案</summary>

1. 第 k 步读第 k−1 步写出的 `B[idx]`，迭代间有真依赖，并行会读到旧值。
2. 前者是边界保护（条件来自索引与形状，编译时可分析）；后者是数据相关分支（条件来自张量内容，运行时才知道）。
3. 不能。本课 steps 是编译时参数；运行时可变次数需要把次数作为设备数据读入并用数据相关循环表达，超出本课范围。

</details>

**本课带走：** 并行声明无依赖，串行声明有依赖；编译时参数决定特化，运行时数据决定分支。下一课进入内存：数据放在哪里，怎样搬。
