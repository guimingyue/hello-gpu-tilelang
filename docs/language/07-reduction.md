# 第 7 课 从行求和到稳定 Softmax

> 本课的问题：把一行数合成一个数（求和），再把一行分数变成一行概率（Softmax）。前者引入**归约**——多对一的数据依赖；后者引入**数值稳定性**——为什么不能直接 `exp(x)`。

## 7.1 归约为什么需要协作

`C[i] = A[i] + B[i]` 里每个输出独立；`sum(row)` 里**一个输出依赖整行**。32 个线程各算一部分，最后必须有人把 32 个局部结果合起来。这就是第 6 课的共享内存 + 屏障的用武之地。

本课采用最直白的结构（教学版，不是性能基线）：

```text
每线程：serial 累加自己负责的列 → 局部和
        ↓ 写入 shared[tid]
T.sync_threads()
线程 0：serial 把 32 个局部和加起来 → 写输出
```

为什么不用 `T.reduce_sum`？本机 TileLang 0.1.15 的 Metal 后端**未注册该归约实现**（编译报 `no reduce implementation is registered`，2026-11-19 实测）。语言里有这个原语 ≠ 每个后端都支持——这是第 0 课“能力随后端而变”的具体例子。手动结构虽然慢，但每一步都看得见，适合入门。

## 7.2 行求和：手算与运行

输入 `[1, 2, 3]`，和为 6。32 线程、补零到 32 列：线程 0–2 各拿到一个数，其余拿到 0，局部和就是 `[1,2,3,0,…]`，线程 0 合并得 6。

```bash
.venv/bin/python code/language/reductions.py
```

本机 M1 实测（2026-11-19）：列宽 1、7、32、33、64 × 5 种输入模式（混合正负、全负、全零、大正偏移、大负偏移）共 25 组求和用例通过，容差 `rtol=2e-6, atol=2e-5`。

**为什么这次不能零容差？** FP32 加法不满足结合律：`(a+b)+c` 与 `a+(b+c)` 可能差一个舍入。32 列、值域 ±10000 时实测最大绝对误差 0.0625——相对 20000 量级的和仍是 3e-6 级别。参考用 FP64 计算，容差按 FP32 舍入量级设定。**“结果不同”不等于“算错”，要先问误差是否在精度允许范围内。**

## 7.3 Softmax：为什么先减最大值

Softmax 定义 `p_i = exp(x_i) / Σ exp(x_j)`。直接算 `exp(10000)` 在 FP32 里溢出成 inf。减去行最大值 `m` 后：

```text
p_i = exp(x_i - m) / Σ exp(x_j - m)
```

数学上完全等价（分子分母同乘 `exp(-m)`），但指数参数全部 ≤ 0，`exp` 结果落在 (0, 1]，不会上溢。这就是“稳定 Softmax”。

kernel 分三遍，每遍都是一次“局部计算 + shared 合并 + 屏障”：

1. 求行最大值 `m`（局部 max → 线程 0 合并 → 发布到 `row_max`）；
2. 求 `Σ exp(x - m)`（同样结构）；
3. 每线程写回 `exp(x - m) / total`。

注意第 2 遍读 `row_max` 前必须有屏障，且 `row_max` 用**独立缓冲**保存——如果复用第 1 遍的 `maxima` 数组，线程 0 写合并结果的同时别的线程可能还在读旧值，又是竞态。

## 7.4 尾部的两种填充

- 求和：补 **0**（加 0 不改变和）；
- Softmax：补 **-inf**（`exp(-inf)=0`，不改变概率分布）。

填充值由**数学语义**决定，不是随便选个“无害的数”。本机实测列宽 33（补到 64）时概率和仍为 1（误差 < 2e-6），验证了这一点。

## 7.5 改一个条件

把某行输入整体加 10000，观察 Softmax 输出几乎不变（平移不变），而直接 `exp` 的朴素版会溢出。再试全零行：概率应为均匀分布 `1/cols`。

## 7.6 练习与自检

1. 为什么线程 0 合并前必须 `T.sync_threads()`？屏障放在 `if tid == 0` 里面行不行？
2. 求和补 0、Softmax 补 -inf，各自的数学理由是什么？
3. 实测求和误差 0.0625 出现在什么量级的输入上？为什么仍可接受？

<details>
<summary>参考答案</summary>

1. 要等所有线程写完 shared 才能读。屏障**不能**放进 `if tid==0`：那样只有线程 0 到达屏障，其余线程永远不到，组内死锁/未定义。屏障必须全组无条件执行。
2. 0 是加法单位元；-inf 经 exp 变 0，是概率意义上的“无贡献”。
3. ±10000 偏移、64 列，和的量级约 20000；0.0625 相对误差约 3e-6，在 FP32 约 1e-7 相对精度 × 累加次数的量级内。

</details>

**本课带走：** 归约 = 局部计算 + 共享合并 + 屏障；浮点比较要讲容差；稳定 Softmax 靠减最大值。下一课把“块”用到二维：矩阵乘。
